Feature deep-dives

How the pieces fit together

Timestamp-based timer

The session is stored as an end timestamp, not a ticking counter. Close the tab, come back an hour later, and the state reconciles without drift — a finished session settles itself and updates the counter without a stale notification.

Generated audio

Brown noise is synthesized with the Web Audio API and the 60 BPM metronome is scheduled on the audio clock with look-ahead, so it never drifts, jitters, or needs an audio file. A shared lease keeps exactly one tab audible across windows.

Closed shadow root

The widget mounts into a closed shadow root in the extension's isolated world. The host page gets no handle, so it can't read, restyle, or script the widget — and the widget never touches page JavaScript.

Sanitised storage

Everything read back from chrome.storage.local is re-validated and clamped, so a tampered or corrupted record can't break or hang the widget. State lives in extension storage, never the page's localStorage.
