About

Built for deep work, respectful of your privacy

Focus Exe is a small, single-purpose browser extension. It does one thing — help you sit down and focus — and it is engineered so that it never needs to know anything about you to do it.

Least privilege

Four permissions, no host access, no <all_urls> permission. The widget only reaches a tab after you summon it.

Zero network

The package makes no requests at all. No analytics, no telemetry, no crash reporting, no remote config, no CDN.

Isolated by construction

The UI runs in a closed shadow root in the extension's isolated world. Pages cannot read it, style it, or script it.

Privacy & security

Least privilege, by construction

What the extension asks for

  • activeTab — reach the current tab, only after you invoke the extension.
  • scripting — inject the widget into that one tab when you summon it.
  • storage — keep your timer state and audio preferences.
  • notifications — tell you when a session or break ends.

No host permissions, no <all_urls>, no browsing history, no bookmarks, no clipboard, no downloads, no cookies.

What it does with your data

  • Nothing leaves your machine: the package makes no network requests at all.
  • No analytics, no telemetry, no crash reporting, no remote config.
  • No remote code: everything needed is inside the package, no eval.
  • Your settings live in the extension's own storage, not in the page's localStorage, so sites cannot read them.

The UI runs in a closed shadow root in the extension's isolated world. Pages cannot read it, style it, script it, or receive anything from it.

Messages between the widget and the background worker are checked against this extension's own ID, and every value read back from storage is re-validated and clamped before it can reach the interface.

FAQ

Common questions

Does it work on every website?

Yes. It has no host permissions at all. When you click the icon (or press the shortcut) the browser temporarily grants access to that one tab, the widget is injected there, and access ends when you dismiss it.

Will the page be able to see or break the widget?

No. The interface is built inside a closed shadow root in the extension's isolated world, so the page has no handle on it. The page's stylesheet cannot reach it either, which is why the widget looks the same on every site.

What happens if I close the tab mid-session?

The timer is kept as a timestamp, not a countdown loop. Reopen the page and summon the widget: if the session finished while you were away it is settled automatically and the counter updated, without firing a stale notification.

Why is there no sound until I click something?

Every browser blocks audio until the page has been interacted with. The first click or keypress inside the widget unlocks the audio context, which is why the toggles ask for a click before you hear anything.

Can I change the 25 minutes, or the deadline date?

They live in src/config.ts — edit and run npm run build. Making them editable in the settings panel is next on the roadmap.

Is it safe to install an unsigned build?

It is the same code that would be submitted for review, and the whole source is in the repository so you can read it before installing. Signed store builds are planned; until then this is the supported install path.
