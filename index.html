Focus Exe

A focus timer that appears when you summon it and disappears when you don't. 25/5 focus and recovery cycles, a countdown to your deadline, brown noise and a 60 BPM neuro-metronome — on any site, in any tab.

Download for Chrome All browsers & install steps
Chrome 102+ Edge Brave Opera Firefox 115+ Safari 16+ ~33 KB download

Core principles

No accounts

Nothing to sign up for. Your settings live in the extension's own storage.

No tracking

No analytics, no telemetry, no network calls at all — you can read the source.

Any website

Summon it on the page you're studying. It holds no standing access to any site.

Works offline

Timers and audio are generated locally, so nothing depends on a server.

Features

Everything a study session needs, nothing it doesn't

No runtime dependencies, no framework, no build-time magic — one small widget that stays out of the way.

25 / 5 focus cycles

Focus for 25 minutes, a 5-minute recovery break, then it flips back automatically and counts the session. Pause, reset or switch early whenever you like.

Deadline countdown

A days / hours / minutes / seconds clock to your exam or deadline, pinned in the widget or popped out in the compact bar.

Brown noise

A soft, low-frequency noise bed generated with the Web Audio API — no looping audio file, no bandwidth, no external request.

60 BPM metronome

A pulsing tick that lines up with a calm breathing rate, scheduled on the audio clock so it never drifts or jitters.

Confirm before you break focus

Starting, pausing, resetting and switching modes all ask first, in the widget or in the compact bar, so a stray click can't cost you a session.

Compact mode

Minimise to a slim bar that keeps the clock, and it collapses by itself the moment you click anywhere else on the page.

How it works

Three steps, then it gets out of the way

Summon it

Click the extension icon, or press Alt+Shift+F. The widget is injected into the current tab only.

Run a session

Confirm the start, put your phone down, and let the flip clock and the metronome carry the session. The audio keeps playing even with the tab in the background.

Dismiss it

Press the shortcut again or click the icon. The widget is removed from the page, audio stops, and only your settings are kept.

Download & install

Pick your browser

One codebase, six builds. Each download is the unsigned package — loading it takes a minute and needs no developer account.

Chrome, Edge, Brave, Opera

Chromium builds are identical. Unzip it, then load the folder unpacked.

chrome://extensions → Developer mode → Load unpacked
  → select the unzipped chrome folder
Chrome .zip Edge .zip Brave .zip Opera .zip

Firefox

Loads as a temporary add-on, which is perfect for trying it out. Sign the zip with web-ext to install it permanently.

about:debugging#/runtime/this-firefox
  → Load Temporary Add-on → pick manifest.json
Firefox .zip

Safari

macOS only. Xcode converts the build into an app extension you can enable in Safari's settings.

xcrun safari-web-extension-converter dist/safari \\
  --macos-only --no-open
Safari .zip

Everyone else

Chromium 102+, Firefox 115+ and Safari 16+ are the minimums. The build pipeline is in the repository if you want to compile it yourself.

git clone https://github.com/vallimuthuraja-git/focus-exe.git
  && cd focus-exe && npm install && npm run pack
Source on GitHub

Signed store listings are on the roadmap; until then these self-hosted packages are the supported way to install it. Keep the shortcut handy — you can rebind Alt+Shift+F in your browser's extension shortcut settings.
